# OER Learning Outcomes

These author-written outcomes describe **Introduction to Python: A Guided Beginner Course**. They summarize the author's existing module objectives; they are not copied from a university catalog and are not official university course outcomes.

After working through the materials, learners should be able to:

1. **Read and predict:** Read short Python programs, explain their steps, and predict their output.
2. **Build small programs:** Modify and write small programs using input, variables, calculations, decisions, loops, and lists.
3. **Organize repeated tasks:** Define and call simple functions to organize repeated tasks.
4. **Test and explain changes:** Test programs, interpret common errors, and document changes or findings in their own words.
5. **Apply and reflect:** Combine introductory skills in a small practical project and explain its purpose, results, and limitations.

See the [course map](COURSE_MAP.md) for the modules supporting each outcome. Module-level objectives remain the detailed learning targets. Function practice is addressed in Module 9; a function is not an additional final-project requirement. [Notebook 12](notebooks/12_guided_mini_project.ipynb) remains the specification for the OER mini project.
