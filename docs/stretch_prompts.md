# Optional Stretch Prompts

These prompts deepen practice with concepts already taught. They are **not required for full credit**, are not extra-credit requirements, and add no final-project features. Choose at most one after the matching lesson if you want more practice. Instructors can offer it instead of a repeated practice attempt, never instead of an essential first example.

Allow about **3–5 minutes** as a provisional guide. Stop and ask for help if it becomes a larger task. Use the original notebook cell: **predict → change one thing → run → explain**. There is no separate submission unless you and your instructor agree to use the work as evidence for an already assigned task.

## A Short Explanation Is Enough

Use: “I expected ___. I observed ___. This happened because ___.” Describe your own result rather than copying someone else's reflection.

Instructors should offer these as choices, not as the next required level. Avoid additional libraries, file handling, complex input validation, or larger applications. Learners who finish early can also improve an output label or explain an existing solution more clearly without writing more code.
